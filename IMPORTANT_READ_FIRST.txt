CinemaGo integration package — 15-film demo

Project base: the newer CinemaGo Django application (Movie/Showtime/Hall/Seat/Ticket schema).
Original older cineseat archive reviewed as reference; incompatible Customer/Event/Booking/Payment models were not merged into the new schema.

15 user-supplied WebP posters are saved separately in the posters/ folder.
After a fresh database migration, run: python manage.py seed_cinemago
This copies the images to local media/posters and inserts the matching movies, cinemas, halls and example showtimes.

For startup instructions, see README.md.
Do not overwrite a different existing project folder. The archive does not include a previous local SQLite database or Git history.

IMPORTANT: A full live Django run could not be completed here because Django was unavailable in the execution environment. Python syntax and ZIP/poster completeness were checked. Run Django system checks and tests on your machine.

All demo times, years, prices and hall sizes are placeholders, NOT verified showtime listings. The booking flow is a classroom demonstration without real payment, QR, login rate limiting or production-grade concurrency guarantees.
