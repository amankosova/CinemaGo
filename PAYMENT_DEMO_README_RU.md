# CinemaGo — demo checkout (RU)

В этой версии есть **учебная**, а не банковская оплата. Не вводите настоящие номера карт, CVV, телефоны и личные платёжные данные.

## Запуск
Из внутренней папки CinemaGo (там, где manage.py):

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_cinemago
python manage.py test
python manage.py runserver
```

Если в предыдущей копии были пользователи и билеты, не подменяйте / не удаляйте `db.sqlite3`. Для миграции существующей базы сначала сделайте резервную копию и примените обновление к рабочему проекту в отдельной копии.

## Проверка вручную
1. Войти в аккаунт, открыть фильм, сеанс, выбрать до 6 мест, Continue.
2. Откроется **Checkout** — места уже удерживаются. Выбрать «Demo card» (Visa ···· 4242, не настоящая карта) или «Demo QR». В QR записан только тестовый номер заказа и сумма; банковского перевода нет.
3. Нажать «Confirm demo payment». После этого бронирование становится оплаченной демо-бронью, билеты появляются в My Tickets.
4. Без оплаты: в другой вкладке попробовать те же места другим аккаунтом — они будут заняты. Спустя 10 минут они снова доступны, а просроченные удержания будут отменены при первом открытии страниц бронирования/билетов. Для регулярной фоновой очистки запускайте `python manage.py expire_reservations` в планировщике раз в минуту.
5. Проверить, что другой пользователь не может открыть `/checkout/<id>/` чужого заказа или оплатить его.

### Особенности
* Обратный отсчёт показывает оставшееся время на основе времени, заданного сервером; окончательное решение об оплате **всегда** принимается сервером.
* Django не хранит никаких реквизитов реальной карты и не соединяется с платёжным провайдером. Пункт «сохранённая карта» — только визуальный **демо-пример**.
* При переключении на другой способ оплаты QR показывается/скрывается без перезагрузки.
* Покупка билета происходит **только после** подтверждения демонстрационной оплаты.
* В проекте есть тесты существующих функций, удержания, оплаты обоими методами, чужого заказа, истечения таймера.
