Изменения CinemaGo (без изменения модели базы данных):
1. Hover preview открывается сбоку от постера, не поверх него. Карточки у правого края открываются влево. На телефоне всплывающее окно скрыто, полные сведения доступны по нажатию на постер.
2. Удалено поле фильтрации по году из каталога; сортировка по году сохранена.
3. Добавлены сортировки по продолжительности (по возрастанию и убыванию) с обработкой на сервере.
4. На главной странице расширены 3 шага How it works короткими описаниями на RU/EN/KZ.
5. Добавлены 3 теста на сортировку и отсутствие фильтра года.

НЕ реализовано в этом изменении: оплата, 10-минутное удержание мест, ограничение неудачных попыток входа. Это отдельные серверные задачи, требующие проектирования и тестирования.

Запуск: python manage.py migrate; python manage.py seed_cinemago; python manage.py test; python manage.py runserver.
Сохраняйте резервную копию своей db.sqlite3, если переносите изменения в основную папку.
