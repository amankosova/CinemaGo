# Обновление CinemaGo: вход и QR билета

- После пяти неправильных паролей с одной пары «имя пользователя + IP адрес» вход временно блокируется на пять минут. Счётчик хранится в SQLite и не сбрасывается от перезагрузки страницы.
- Сообщения об ошибке входа и блокировке переведены на RU/EN/KZ; оставшееся время показывается таймером, но сервер решает, когда вход снова доступен.
- My Tickets: у каждого оплаченного билета есть кнопка «Показать QR билета». PNG доступен только владельцу билета; до оплаты или после отмены он недоступен.
- QR содержит подписанный адрес демо-проверки; это НЕ оплата и НЕ реальная система контроля входа. Личные данные не содержатся в QR.
- Оформление основного CinemaGo сохранено.

## Запуск

Создайте резервную копию вашей db.sqlite3. Используйте прежнюю рабочую базу, если хотите сохранить пользователей, фильмы и билеты. Затем:

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py test
python manage.py runserver
```

Если на отдельной новой базе нет фильмов: `python manage.py seed_cinemago`.

## Проверить

1. Неправильный пароль 5 раз — ошибка и отсчёт пяти минут.
2. Даже правильный пароль во время блокировки — не пускает; по окончании блокировки снова пускает.
3. В My Tickets только после завершённой демо-оплаты появляется QR; у двух билетов разные QR.
4. QR одного пользователя нельзя запросить из аккаунта другого.
5. Проверка QR отменённого билета возвращает «Недействителен».

Сайт — учебный проект, не для настоящего банка или живой кассы. Для эксплуатации необходимо дополнительно проверить безопасность, ограничения запросов и интеграцию с реальным эквайрингом.
