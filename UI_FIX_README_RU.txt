CinemaGo: исправления интерфейса от 13.11.2026

1. Старый главный баннер и стиль сохранены.
2. Хедер: на широких экранах одна строка; языки KZ/RU/EN в выпадающем меню.
3. Карточки фильмов: информация скрыта до наведения, не дублируется в сетке.
4. Главная: четыре фильма в одной сетке, кинотеатры карточками с фото и подписями источников, шаги покупки с кружками.
5. Фото кинотеатров загружаются из внешних сайтов и могут не отображаться без интернета или из-за запрета сторонней загрузки. В таком случае сохранится фон карточки. При публикации проверьте право на использование фото и при необходимости замените их собственными/лицензированными изображениями.
6. Текущая SQLite не вложена. Сохраняйте имеющийся db.sqlite3 и медиа в рабочем проекте. Не перезапускайте команду seed_cinemago на своём рабочем проекте без резервной копии.

Команды (из папки CinemaGo):
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py test
python manage.py runserver

После замены нажмите Ctrl+Shift+R для перезагрузки CSS. В URL CSS также изменена версия, чтобы сбросить старый кэш браузера.
