CinemaGo — исправление интерфейса (13.11.2026)

ЧТО ИЗМЕНИЛОСЬ:
1. В хедере появились рабочие ссылки My Tickets (для пользователя) и Admin Panel (только суперпользователю).
2. В профиле пользователя появились ссылки My Tickets, а для суперпользователя — Admin Panel.
3. Три настоящих переключателя языка 🇰🇿 KZ / 🇷🇺 RU / 🇺🇸 EN. Они отправляют POST в Django set_language, сохраняют выбор в cookie и возвращают на текущую страницу. Добавлены скомпилированные locale-файлы ru/kk. Кнопки и основные страницы переведены. Английский — исходный язык.
4. При наведении или клавиатурном фокусе карточка фильма показывает превью (жанры, минуты, возраст, режиссёр, краткое описание). На телефоне информация остаётся доступной на странице фильма.
5. На главной оставили оригинальный баннер «Your seat is waiting.» и картинку. Ниже появились «Сейчас в кино», «Наши кинотеатры» и «Как это работает».
6. Сохранены исходные 15 постеров, подробные данные 15 фильмов, варианты RU/EN/KZ в данных, бронирование и My Tickets.
7. Панель /panel/ теперь допускает только суперпользователей и на сервере (раньше могли входить обычные staff).

ВАЖНО: это обновление интерфейса и каталога. Не добавляли оплату, QR, лимит на входы. Часть сообщений Django и данные о кинотеатрах пока имеют неполные переводы, полный аудит локализации ещё нужен.

ПРОВЕРКА:
1. Скопировать ZIP отдельно, открыть вложенную папку CinemaGo (там находится manage.py).
2. pip install -r requirements.txt
3. python manage.py migrate
4. python manage.py seed_cinemago
5. python manage.py check
6. python manage.py test
7. python manage.py createsuperuser (если ещё нет админа в этой базе)
8. python manage.py runserver
Открыть http://127.0.0.1:8000/ , /movies/ , /my-tickets/ , /panel/

Важное про старую SQLite: в новом ZIP намеренно НЕТ db.sqlite3. Если надо сохранить старые билеты, используйте копию своего db.sqlite3 в этой папке, ПЕРЕД migrate сделайте резервную копию. Не копируйте базу поверх работающего сервера. seed_cinemago добавляет демоданные, не удаляет билеты.

ОГРАНИЧЕНИЯ ПРОВЕРКИ:
В среде сборки Django не установлен и его не удалось установить из сети. Поэтому здесь проверены структура ZIP, Python-синтаксис, locale-файлы и связи шаблонов, но реальный запуск Django и тесты надо выполнить по командам выше на вашем компьютере.
